# SCB administrative reference tables

These CSV files are a checked-in snapshot of Statistics Sweden (SCB) code
lists, generated by [`scripts/download_scb_references.py`](../../scripts/download_scb_references.py).
All code columns are strings: leading zeroes are significant.

| File | Effective date | Contents |
| --- | --- | --- |
| `counties-2026.csv` | 2026-01-01 | 21 county codes and names |
| `municipalities-2026.csv` | 2026-01-01 | 290 municipality codes and names, linked to county code |
| `parishes-2026.csv` | 2026-01-01 | Church parish (LKF) codes and names, linked to municipality code |

Refresh the snapshot with:

```bash
uv run python scripts/download_scb_references.py
```

Sources:

- [Counties and municipalities in code order](https://www.scb.se/hitta-statistik/regional-statistik-och-kartor/regionala-indelningar/lan-och-kommuner/lan-och-kommuner-i-kodnummerordning/)
- [Parishes](https://www.scb.se/hitta-statistik/regional-statistik-och-kartor/regionala-indelningar/forsamlingar/)
